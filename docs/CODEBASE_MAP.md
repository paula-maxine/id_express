# Codebase Map

[Back to README](../README.md)

Paths are relative to the repository root. "Live" means reachable from
`lib/main.dart` through imports; "inactive" means present but not imported by
the running app.

## `lib/main.dart` (live)

Entry point. Wraps start-up in `runZonedGuarded`, sets `FlutterError.onError`
and `PlatformDispatcher.instance.onError`, initializes Firebase with
`DefaultFirebaseOptions.currentPlatform`, enables Firestore persistence with an
unlimited cache, then runs `ProviderScope(child: IdExpress())`.

## `lib/app/` (live)

`id_express.dart`: the root `MaterialApp.router`, reading `goRouterProvider`
and `appThemeProvider`. Light theme only.

## `lib/app_exporter.dart` (live)

Barrel that re-exports Flutter, Riverpod, go_router, google_fonts, intl, all
Firebase SDKs, uuid, image_picker, file_picker, cached_network_image,
flutter_svg, and the `app/`, `core/`, `features/` and `routes/` barrels. Feature
files import only this file plus `riverpod_annotation`.

## `lib/data/` (mostly inactive)

An earlier data layer built on `json_serializable`: cloud services per
collection (`cloud/`), a sembast offline queue (`local/sync_service.dart`),
repositories (`repository/`), models with generated `.g.dart` files
(`model/`) and an empty `mock/` barrel. The live app imports only
`cloud/audit_cloud_service.dart` (and its `app_exception.dart`) and
`model/audit_log_model.dart` (imported as `legacy`) for audit writes.
`test/model_test.dart` tests `model/application_model.dart`.

## `lib/global/`, `lib/services/`, `lib/utils/` (inactive)

Earlier theme, widgets, constants and validators (`global/`), Firebase wrapper
services (`services/`, imported only by the inactive `data/` layer) and a
UUID helper (`utils/`). Not imported by the live app.

## `lib/firebase_options.dart`

Generated by the FlutterFire CLI. Contains Firebase client identifiers for web,
Android, iOS and Windows; macOS and Linux entries hold `YOUR_...`
placeholders.

## `scripts/`

`bump_version.dart` (minor and build increment, rolls major after minor 19,
updates `web/version.txt`) and `deploy_testing.dart` (optional bump, Flutter
release builds, multipart upload to AppSend, prints install links). Documented
in `scripts/README.md`.

## Firebase configuration (root)

| File | Purpose |
| --- | --- |
| `firebase.json` | Firestore rules/index paths; Hosting with SPA rewrite, no-cache headers for the loader files and `version.txt`, one-year immutable cache for static assets; FlutterFire platform mapping |
| `.firebaserc` | Default Firebase project alias |
| `firestore.rules` | Role- and ownership-based rules (see SYSTEM_DEEP_DIVE) |
| `firestore.indexes.json` | 9 composite indexes on `applications`, `appointments`, `notifications` |
| `storage.rules` | `documents/{uid}/**` owner write under 20 MB, staff read |

## Platform runners

`android/` (Kotlin DSL Gradle, AGP 9.0.1, Kotlin 2.3.20, Gradle 9.1.0, Java 17,
Google Services plugin 4.3.15), `ios/` (deployment target 15.0, Swift Package
Manager `Package.resolved` committed), `macos/` (10.15), `web/` (custom loader in
`index.html` that fetches `version.txt` with `no-store`, and on a new value
clears the Cache API and unregisters service workers before injecting
`flutter_bootstrap.js`),
`windows/`, `linux/` (Flutter template runners).
